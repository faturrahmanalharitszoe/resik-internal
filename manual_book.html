Selamat Datang

Mengenal Resik Internal

Selamat datang di aplikasi Resik Internal — platform kolaborasi internal perusahaan yang dirancang untuk mempermudah komunikasi tim, pengelolaan dokumen, dan pencatatan pekerjaan dalam satu tempat. Aplikasi ini menghadirkan tiga fitur utama yang saling terintegrasi:

Chat

Komunikasi real-time melalui ruangan (grup) maupun pesan pribadi dengan rekan kerja.

Folder Bersama

Dokumentasi dan pelacakan surat/dokumen masuk & keluar antar divisi atau proyek.

Notion Workspace

Kanvas digital untuk mencatat, mendokumentasikan, dan melacak pekerjaan secara interaktif.

Tentang panduan ini: Buku panduan ini menjelaskan langkah demi langkah cara menggunakan setiap fitur utama Resik Internal, lengkap dengan tangkapan layar antarmuka aplikasi untuk memudahkan Anda mengikuti setiap proses.

01 — Fitur Chat
Resik Internal · Panduan Pengguna
Modul Komunikasi

01Fitur Chat (Percakapan)

Fitur Chat memungkinkan Anda untuk berkomunikasi dengan rekan kerja secara real-time, baik melalui grup (ruangan) maupun pesan pribadi (Direct Message).

1.1Mengakses Chat

  • Klik ikon Chat pada panel navigasi di sebelah kiri (Activity Bar).
  • Anda akan melihat daftar Ruangan (Rooms) dan daftar Pengguna Online.
Gambar: Tampilan utama fitur Chat dengan daftar ruangan dan pengguna online

1.2Membuat Ruangan Baru (Grup)

  1. Pada sidebar sebelah kiri, cari bagian Ruangan.
  2. Klik tombol + (Buat Ruangan Baru) di sebelah kanan label.
  3. Masukkan nama ruangan (contoh: tim-marketing).
  4. Klik tombol Buat.
Gambar: Dialog pembuatan ruangan baru

1.3Mengirim Pesan

  1. Pilih ruangan atau nama pengguna dari sidebar.
  2. Ketik pesan Anda di kotak input bagian bawah.
  3. Klik tombol Kirim (ikon panah) atau tekan tombol Enter.
Gambar: Jendela percakapan dan kotak input pesan

1.4Manajemen Anggota Ruangan

  • Untuk melihat daftar anggota ruangan, klik ikon Anggota di pojok kanan atas area chat.
  • Untuk menambahkan anggota baru, buka panel anggota lalu klik tombol + Tambah Anggota.
Gambar: Panel manajemen anggota ruangan

Kamus Tombol & Ikon - Modul Chat

  • Ikon Chat : Membuka panel utama Chat dari bilah navigasi kiri.
  • + Buat Ruangan Baru : Membuat grup percakapan baru untuk komunikasi banyak orang.
  • Ikon Panah (Kirim) : Mengirim teks atau pesan yang sudah diketik ke ruang obrolan.
  • Ikon Anggota : Menampilkan panel daftar peserta yang tergabung di ruangan tersebut.
  • + Tambah Anggota : Mengundang peserta/rekan kerja baru ke dalam grup obrolan.

Modul Manajemen Dokumen

02Fitur Folder Bersama

Fitur Folder Bersama digunakan untuk mendokumentasikan dan melacak surat/dokumen masuk dan keluar antar divisi atau proyek.

2.1Mengakses Folder Bersama

  • Klik ikon Folder pada navigasi kiri (Activity Bar) atau klik menu Folder Bersama di sidebar.
Gambar: Halaman utama Folder Bersama

2.2Mengunggah Dokumen Baru

  1. Pada halaman Folder Bersama, klik tombol Unggah Dokumen di bagian atas (banner).
  2. Akan muncul form pengisian, lengkapi data berikut:
    • Tipe Dokumen & Sub-Tipe
    • Proyek
    • Nomor & Nama Dokumen
    • Tanggal Dokumen
    • Deskripsi (opsional)
    • Penerima Dokumen
  3. Klik pada area Berkas File atau seret file (drag and drop) ke area tersebut (format yang didukung: .pdf, .doc, .docx, .xls, .xlsx).
  4. Klik Upload Dokumen.
Gambar: Form pengisian data dokumen (bagian 1)

2.3Memantau Dokumen Masuk dan Keluar

  • Di halaman utama Folder Bersama, terdapat tab Masuk dan Keluar.
  • Masuk: Menampilkan dokumen yang ditujukan ke divisi/pengguna Anda.
  • Keluar: Menampilkan dokumen yang Anda unggah/kirimkan.
  • Gunakan Kotak Pencarian atau filter Bulan & Tahun untuk mempermudah pencarian dokumen spesifik.
Gambar: Tab pemantauan dokumen Masuk dan Keluar

Kamus Tombol & Ikon - Folder Bersama

  • Ikon Folder : Membuka modul manajemen dokumen dari panel navigasi.
  • Unggah Dokumen : Tombol utama di halaman depan untuk memulai proses pengiriman/penyimpanan dokumen baru.
  • Area Berkas File : Kotak area untuk memilih dokumen dari komputer Anda (bisa di-klik atau ditarik ke dalam kotak).
  • Upload Dokumen : Menyimpan dan mengirimkan dokumen beserta formulir yang telah diisi ke sistem.
  • Tab Masuk / Keluar : Berpindah tampilan antara daftar surat yang ditujukan ke Anda (Masuk) vs. surat yang Anda buat/kirim (Keluar).
  • Kotak Pencarian : Melakukan filter cepat untuk mencari dokumen spesifik berdasarkan nama, nomor, atau proyek.

Modul Kolaborasi & Catatan

03Fitur Workspace

Fitur Workspace berfungsi sebagai kanvas digital untuk mencatat, membuat dokumentasi, dan melacak pekerjaan dengan dua mode utama: Halaman Catatan (Wiki) untuk teks bebas dan Database untuk data terstruktur dengan berbagai tampilan interaktif (Table, Board, Calendar, Gallery, List, dan Timeline).

3.1Mengakses Workspace

  • Klik ikon Workspace pada panel navigasi (Activity Bar).
Gambar: Tampilan Workspace

3.2Membuat dan Mengedit Halaman

Workspace memiliki dua jenis halaman yang bisa Anda buat:

📄
Halaman Wiki / Catatan

Halaman kosong untuk menulis dokumen, wiki, notulen rapat, catatan proyek, atau materi kolaborasi bebas dalam format teks kaya (rich text).

📅
Database

Halaman terstruktur untuk melacak tugas dan proyek. Mendukung tampilan Table, Board (Kanban), Calendar, Gallery, List, dan Timeline.

Membuat Halaman Baru

  • Klik tombol + Halaman Baru di pojok kanan atas sidebar Workspace.
  • Masukkan judul halaman, lalu pilih tipe halaman:
    • Halaman Wiki / Catatan — halaman catatan biasa untuk menulis dokumen, wiki, atau panduan.
    • Database (Tabel/Kalender) — halaman terstruktur untuk melacak tugas dan proyek dengan tampilan Table, Board, Calendar, Gallery, List, atau Timeline.
  • Halaman baru akan langsung dibuka dan siap digunakan.
Gambar: Mode edit halaman dengan toolbar pemformatan teks

3.3Mengganti Ikon dan Cover Halaman

  • Ikon Halaman: Klik ikon emoji di sebelah kiri judul halaman untuk memilih emoji baru dari menu pop-up.
  • Cover Halaman: Klik tombol Ganti Cover di sudut kanan atas area header (gradien warna) untuk memperbarui latar belakang header halaman.

3.4Mode Halaman Wiki / Catatan

Halaman Catatan digunakan untuk menulis dokumentasi, notulen rapat, catatan proyek, atau materi kolaborasi bebas dalam format teks kaya (rich text).

  • Setiap halaman baru yang dibuat secara default bertipe Catatan (Wiki).
  • Setiap halaman bisa memiliki Sub-halaman (anak halaman) untuk membuat struktur dokumentasi hierarkis.
  • Klik tombol + Halaman Baru untuk membuat sub-halaman di bawah halaman yang sedang aktif.

Mengedit Konten Halaman Wiki / Catatan

  • Buka halaman wiki/catatan yang ingin diedit dari sidebar.
  • Klik tombol Edit di pojok kanan atas area konten.
  • Saat mode edit aktif, gunakan toolbar untuk memformat teks:
    • H — Heading (Judul)
    • B — Bold (Tebal)
    • I — Italic (Miring)
    • • — Bullet List (Daftar Tak Bernomor)
    • 1. — Numbered List (Daftar Bernomor)
    • 🔗 — Sisipkan Tautan (Link)
    • 🖼️ — Sisipkan Gambar
  • Klik Simpan setelah selesai, atau Batal untuk membatalkan perubahan.
Gambar: Mode edit halaman dengan toolbar pemformatan teks

Pengaturan Akses Halaman

Setiap halaman memiliki pengaturan akses untuk mengontrol siapa yang bisa melihatnya:

  • Public — Semua pengguna yang sudah login bisa melihat halaman ini.
  • Role-based — Hanya pengguna dengan level tertentu (Staff, Management, atau Top Management) yang bisa mengakses.
  • Divisi — Hanya anggota divisi tertentu (Marketing, SDM, Keuangan, Operasional) yang bisa mengakses.

Untuk mengubah pengaturan akses, klik tombol Akses di pojok kanan atas saat mode edit aktif, lalu pilih tipe akses yang diinginkan.

3.5Menggunakan Mode Database

Halaman Database digunakan untuk melacak tugas dan proyek dengan data terstruktur. Database mendukung berbagai tampilan visual yang bisa ditukar sesuai kebutuhan.

Menambah Baris Data

  • Klik tombol + Baris Baru di pojok kanan atas area database.
  • Masukkan judul baris, lalu isi properti seperti Status, Priority, Assignee, Start Date, dan Deadline.

Mengedit Data via Peek Panel

  • Klik pada judul baris (atau klik di mana saja pada baris) untuk membuka panel edit (peek panel).
  • Di dalam peek panel, Anda bisa mengubah: Judul, Ikon, Status, Priority, Assignee, Start Date, Due Date, Tags, dan Deskripsi/Notulen (bagian teks kaya di bagian bawah panel).
  • Klik Simpan untuk menyimpan perubahan, atau tutup panel untuk membatalkan.

Mengubah Tampilan (View)

Gunakan tab di bagian atas database untuk beralih antar tampilan:

  • Table — Tampilan tabel spreadsheet dengan kolom Status, Prioritas, Divisi, Tanggal, dan Kemajuan.
  • Board — Tampilan Kanban dengan 3 kolom: To Do, In Progress, Done. Data bisa di-*drag-and-drop* antar kolom.
  • Calendar — Tampilan kalender bulanan. Baris yang memiliki Deadline akan muncul pada tanggal yang sesuai.
  • Gallery — Tampilan kartu (card) dengan cover gambar, status, dan assignee.
  • List — Tampilan daftar checklist. Centang checkbox untuk menandai tugas selesai.
  • Timeline — Tampilan Gantt chart horizontal berdasarkan Start Date dan Deadline.

Menyaring Data (Filter)

  • Gunakan dropdown filter di bagian atas untuk menyaring berdasarkan Status, Priority, atau Assignee.
  • Gunakan kotak pencarian untuk mencari baris berdasarkan judul atau deskripsi.
Gambar: Tampilan Database dengan berbagai mode tampilan

Kamus Tombol & Ikon - Workspace

  • + Halaman Baru : Membuat dokumen catatan baru yang kosong di dalam folder yang aktif.
  • Tombol Edit : Membuka halaman ke mode pengeditan agar konten (teks, gambar, tabel) dapat dimodifikasi. Berlaku untuk halaman Catatan maupun Database.
  • Tombol Simpan : Menyimpan dan mengonfirmasi semua perubahan konten ke server secara permanen.
  • Tombol Batal : Membatalkan pengeditan dan mengembalikan konten ke versi terakhir yang tersimpan.
  • Ganti Cover & Ikon : Membuka jendela khusus (pop-up) untuk memilih gambar header dan emoji yang merepresentasikan halaman.
  • Tombol Akses : Mengatur siapa yang boleh melihat halaman berdasarkan peran (role) atau divisi.
  • Menu Filter : Menyaring data tabel berdasarkan prioritas, status (mis. 'Done', 'In Progress'), atau parameter lainnya.
  • + Baris Baru : Menambahkan entri data baru ke bagian bawah tampilan tabel (Database).
Tip: Navigasi antar fitur sangat mudah, cukup gunakan tombol-tombol utama (Chat, Workspace, Folder) di panel Activity Bar (sebelah paling kiri layar) kapan pun Anda membutuhkannya.
